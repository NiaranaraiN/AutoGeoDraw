# 图纸项目信息

用 APPLOAD 加载同目录的 VlsProjectInfo.lsp。加载 SectionCutter 时会自动加载本程序。单独部署时，将 ProjectInfo 目录加入 CAD 支持文件搜索路径，或设置 *project_info_root* 指向该目录。

| 命令 | 用途 |
| --- | --- |
| PROJECTINFO | 查看本次扫描的 GCD 高程范围，创建或编辑地层表。确定后两张表一并写入当前图纸。 |
| PROJECTGCD | 重新扫描高程点并写入项目信息表，可独立于地层表运行。 |
| SCLAYERS | 从 SectionCutter 打开同一维护窗口。 |

项目信息表保存模型空间 GCD 图层中 CASS 高程点块的正值高程最小值和最大值。先解析块的高程属性，属性缺失或无法解析时读取块插入点的世界坐标 Z。没有正值时，两项均为空。

地层表依次为层序编号、亚层序、地层代号、类别、材料性质、填充图案代码。层序编号用正整数。同一层序编号可分多个亚层，按亚层序排列，纯数字按数值排列。亚层序可留空。完整地层编号沿用“地层代号/亚层序”。覆盖层的层序应在岩层上方。两表随 DWG 保存。

SCEDIT 读取当前图纸的地层表，缺表时打开初始化窗口。有旧剖面地层记录时，初始化可带出当前剖面的地层行。新剖面按项目层序录入。旧剖面沿用其已保存的完整编号和顺序，编辑厚度时按完整编号更新匹配的地层属性。地层表中的增删、改编号或重新排序不会重新分配旧剖面的厚度和尖灭数据。
