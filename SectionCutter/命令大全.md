# SectionCutter 命令大全

本页列出当前试测版的 34 条 CAD 命令。加载 [VlsSectionCutter.lsp](VlsSectionCutter.lsp) 后，直接在 CAD 命令行输入表中的命令名。需要从头操作时，见 [实现流程](实现流程.md)。

## 开始使用

- 在模型空间用 `APPLOAD` 加载主程序。同目录下的 LSP 和 DCL 文件需一起保留，项目的 `ProgramTemplate` 和通用工具模块需能被程序找到。
- 提示「选择剖面」时，点关联的平面剖切线或剖面成员。图形已删或不好选时，在选择提示处回车，再输入列表序号。
- 高程、厚度和里程用米。输入比例时只填分母，例如 `200` 表示 1:200。控制点里程从剖切起点算，起点填 `0`，终点填剖切线的实际长度。例如起始桩号是 `1000 m`，要录入 `1020 m` 处的点，就填 `20`。
- `SCEDIT` 录入厚度、水位和风化，`SCJG` 录入构造交点。点选平面剖切线或剖面地表线定位，也可输入 `M` 手输里程。选点时两条线临时显示同类已有点，点圆圈或文字可编辑原点。按空格或回车提交并重绘。

## 新建剖面与打开面板

| 命令 | 用途 | 操作要点 |
| --- | --- | --- |
| `SCDXPM` | 生成地形剖面和图框 | 选开放且不自交的平面剖切线，确认方向，填名称、比例、底界高程和刻度。复核提取到的高程，最后点图上的剖面基点。已有剖面时可选恢复、更新地形或完全重建。 |
| `SCDZPM` | 从平面线开始绘制地质剖面 | 先走一遍地形流程，然后自动打开地质操作面板。首次可选「地层厚度控制点」。关闭面板时，已完成的地形会保留。 |
| `SCDZTT` | 在已有剖面上打开地质操作面板 | 选已有剖面，在面板中选一项操作并确定。每次打开面板执行一项，后续可重新进入面板或直接输入对应命令。 |
| `SCMANAGE` | 打开剖面管理面板 | 与 `SCDZTT` 打开同一个面板。可从这里进入地质录入、检查、更新、恢复及导出等操作。 |
| `SCSCPM` | 从相交剖面取得岩层厚度 | 新建或选择目标地形，逐个确认相交的来源剖面。各来源的岩层编号和层序须一致，目标已有统一地层表覆盖层时可用 `SCEDIT` 补录。遇到基岩顶界高程差异时，按提示选择保留界面高程或各层厚度。覆盖层、风化、构造交点和水位在目标剖面另行录入。 |
| `SCDEMO` | 生成合成示例剖面 | 在空白区域指定基点，查看示例地形、地层填充、尖灭、水位和图框。 |

## 录入地质数据

| 命令 | 用途 | 操作要点 |
| --- | --- | --- |
| `SCLAYERS` | 维护图纸项目信息及地层表 | 填写层序编号、亚层序、地层代号、类别、材料性质和填充图案。层序编号为正整数，亚层序可留空。有亚层时，完整编号写作“代号/亚层序”。 |
| `SCEDIT` | 录入厚度、水位及风化下限 | 读取图纸地层表，缺表时打开初始化窗口。逐点填写厚度、距地表的水位埋深及距基岩顶界的四个风化下限。水位可留空，四个风化下限均须填写并按由浅到深排列。 |
| `SCJG` | 录入构造交点 | 在平面图上靠近目标交点点选构造线。程序读取该线的地质属性，按上层所在方位和交点线形转换前后侧。字段缺失时先选择经过交点的构造线和类型，保存属性后重新读取。未关联构造线的点可按里程手工录入。前侧为剖面左侧，后侧为右侧。一般基岩分界和断层按界面产状出线，褶皱、涉及覆盖层的接触和近水平界面显示位置标记。 |
| `SCWEATHER` | 打开控制点表 | 与 `SCEDIT` 相同。 |
| `SCCOVER` | 编辑独立覆盖层 | 可录入或修改竖向厚度、设置尖灭、清除独立覆盖层。厚度点须含起点和终点。覆盖层已经列在统一地层表中时，用 `SCEDIT` 改厚度、`SCPINCH` 设尖灭。 |
| `SCPINCH` | 设置地层尖灭 | 选目标层，输入尖灭里程和该层存在的一侧。程序使顶、底界在尖灭点收敛，确认缺失侧按零厚度处理。 |
| `SCWATER` | 录入或清除地下水位 | 可追加修改、整组替换或清除。选实际高程或地表以下的竖向埋深，逐点输入里程及数值。同一组水位点应属于同一个水位面。 |
| `SCDELETEPOINT` | 删除指定控制点 | 选厚度、构造交点、风化或水位，按列出的控制里程输入要删的位置，再确认重算。厚度须至少保留两点，已有尖灭约束的厚度点禁止直接删除。 |
| `SCAPPDIP` | 核对构造投影和产状 | 选择已录构造交点的剖面，在命令行查看剖切方位、界面及两侧地层的真实产状、视倾角、左右倾斜方向和图上角度。此命令只查看。 |

## 修改图面与出图参数

| 命令 | 用途 | 操作要点 |
| --- | --- | --- |
| `SCDESC` | 填写剖面描述 | 编辑方位、位置和工程地质条件评价等栏目。填 `-` 表示留空，输入 `\P` 换行。 |
| `SCSTYLE` | 设置某层的填充样式 | 输入完整地层编号，设置填充图案、图案比例、颜色、图案原始基准角、额外旋转角和类别。自定义图案需让 CAD 能找到同名 PAT 文件。 |
| `SCSET` | 修改剖面参数 | 修改名称、横纵出图比例、底界高程、起始桩号和刻度间距。若源图平面比例填错，按正确比例重新建剖面。 |
| `SCTEXT` | 更新已有剖面的文字格式 | 原位更新文字样式及产状标注的边框和背景遮罩，保留文字内容和位置。 |
| `SCFRAME` | 单独更新图框 | 按当前模板重建描述框、标尺和栏目文字，保留地质线、填充和水位等实体。 |
| `SCMOVE` | 整体移动剖面 | 选已有剖面，再点新基点，整套已保存成果随之移动。 |
| `SCADOPT` | 采纳 CAD 中手工修改的成果 | 手工修改剖面线形、文字或填充旋转后，运行此命令把受支持的修改保存到成果快照，供重绘和恢复使用。 |

## 检查、重绘与恢复

| 命令 | 用途 | 操作要点 |
| --- | --- | --- |
| `SCCHECK` | 检查剖面状态 | 报告缺失成员、身份不符、未采纳修改及平面线关联状态。此命令只检查。 |
| `SCDRAW` | 按上次确认的成果重绘 | 用已保存的成果快照整体重绘，适用于图面需要重新生成且仍采用上次确认数据的情况。 |
| `SCRESTORE` | 恢复已保存的剖面图形 | 选 `Missing` 补齐缺失图元，或选 `Full` 整体恢复。全部图元丢失时，在选择提示处回车，从记录列表选剖面。 |
| `SCREPAIR` | 修复剖面成员关联 | 依据图元的剖面身份和角色重新登记关联。若仅缺图元，修复后可用 `SCRESTORE` 补齐。 |
| `SCRELINK` | 重新关联平面剖切线 | 先选剖面，再选与已保存剖切几何一致的平面线。 |
| `SCUPDATE` | 重读测量资料并重算剖面 | 测量来源更新后使用。确认后重新提取地形，并用保存的地质控制数据重算。已采纳的人工线形会被重算结果替换。 |
| `SCREBUILD` | 完全重新剖切 | 选择旧剖面并确认放弃旧地质资料，再录入方向、参数和出图位置。新地形成功保存后，程序移除旧记录和残留成果。之后可用 `SCDZTT` 重新填图。 |
| `SCCLEAN` | 清理无用剖面记录或孤立关联 | 从候选列表勾选并再次确认。删除记录会失去该记录对应的恢复依据。清理孤立关联时保留原图元。 |

## 导入、导出与备份

| 命令 | 用途 | 操作要点 |
| --- | --- | --- |
| `SCEXPORT` | 导出完整恢复包 | 选剖面并指定 `.scdata` 文件。恢复包包含控制数据、样式及已确认的绘图成果。 |
| `SCIMPORT` | 从恢复包重建剖面 | 打开 `.scdata` 文件，按提示指定绘制位置。同编号时可恢复原剖面或另建副本。导入后需要关联平面线时用 `SCRELINK`。 |
| `SCCSV` | 导出可编辑的控制数据表 | 选剖面并保存 CSV，可用 Excel 查看和修改地层、厚度、构造交点、风化、水位等控制数据。 |
| `SCCSVIMPORT` | 从 CSV 批量更新控制数据 | 选原剖面和完整的 UTF-8 CSV，校验并试算后确认整表替换和重绘。保留表头、单位和完整的控制点组。 |

常用手测顺序为 `SCDZPM` → 面板中选控制点录入 → `SCJG` → `SCCHECK` → 保存 DWG。编辑现有剖面时从 `SCDZTT` 进入。
