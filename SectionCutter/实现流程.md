# VlsSectionCutter 实现流程

> 记录当前操作流程及后续设计。详细数据和计算规则见《VlsSectionCutter规划.md》。

新建和跨剖面取值共用剖面编辑及出图流程。当前改版将厚度、构造交点和风化下限作为同一剖面的独立数据项，按用途分别录入。

## 命令分工

- `SCDXPM`：切地形剖面，选择平面线并生成地形及特征点。
- `SCDZTT`：在已有地形剖面上，按确认数据绘制或重绘地质成果，提供数据录入编辑、采纳修改及恢复入口，不重新切取地形。
- `SCDZPM`：连续执行 `SCDXPM → SCDZTT`，从选平面线到生成地形和地质成果，直接接续当前剖面，不重复选择；地质阶段取消后可保留已完成的地形并用 SCDZTT 接续。
- `SCSCPM`：根据平面剖切线交点读取已有剖面，生成新剖面；地形不足时先完成地形生成。

开发语言为Visual LISP + DCL，面向Windows AutoCAD和ZWCAD。以下为目标流程，试用版支持范围另行注明。

## 一、根据平面剖切线生成地质填图

完整执行使用 SCDZPM；分步执行先用 SCDXPM 完成步骤1～2，再用 SCDZTT 完成后续步骤。

### 1. 选择剖切线及设置参数

选择平面剖切线，显示方向箭头并确认起终点、剖面左右方向。设置剖面名称、编号、起始桩号、平面比例、剖面横纵比例、插入位置、基准高程和绘制范围，选择是否绘制地下水位线。比例按出图习惯输入，例如 `1:200` 换算为 0.2 米/CAD单位。

如果平面线已有剖面关联，提示进入已有剖面编辑，避免无意重复建立关联。

### 2. 提取交点并生成地形

查找测量图层及地质图层的交点，分别形成高程点和地物、地质特征点；同一交点可以同时属于两类。检查高程异常、同里程冲突及缺失数据，用户复核后生成地形线，并建立剖面与平面线的关联。

端点缺高程时，默认选择“延伸DGX插值”，也可选“手工输入”。沿起点首段反向、终点末段正向取得外侧最近有效DGX交点，与原剖切线内侧最近有效高程点按距离插值。显示结果和外侧距离后可采用或改为手工值；没有有效内外两侧高程或发生冲突时转手工输入。补点保持原剖切线长度，两端高程和手工/插值来源均保存，恢复时沿用。无高程的地质交点在补齐后的有效地形线内取得高程。

### CSV修改控制数据

运行SCCSV导出 → Excel修改并另存为CSV UTF-8 → SCCSVIMPORT选择原剖面及完整表 → 检查编号、字段、单位、层序、产状、尖灭及地形覆盖范围 → 试算区域 → 用户确认整表替换和重算 → 保存DWG。验证失败不修改原成果；导入成功可用UNDO回退。完整成果备份仍用SCEXPORT。

### 3. 录入地层、厚度、水位及风化下限

`SCDZPM` 完成地形后打开与 `SCDZTT` 相同的编辑面板。用 `SCEDIT` 读取图纸地层表，缺表时打开项目信息初始化。同一地层有多种岩性时可用不同亚层编号，例如 `Q4/1` 粘土、`Q4/2` 砂土，普通地层可留空。点选平面剖切线或剖面地表线后，每个控制点按完整编号填写厚度。输入 `M` 可手输距剖切起点的米数，空格或回车结束选点。厚度点至少两组，已有同里程数据会带出。用 `SCLAYERS` 维护图纸共享地层表。旧剖面继续按已保存的完整编号和顺序录入，匹配到的地层采用共享表的类别、材料性质和填充图案。已有 `SCCOVER` 覆盖层可沿用。

每个控制点在一张表内依次填写厚度、地下水位埋深、四个风化下限。地下水位埋深从地表向下量，留空跳过，`0` 表示水位在地表。全、强、中、微风化下限从基岩顶界向下累计，按由浅至深填写，例如 `2、5、9、14 m`。有至少两个相应控制点时绘制水位线或风化线。

选择厚度点或构造交点时，平面剖切线与剖面地表线都临时显示该类已录点的圆圈和里程。构造交点还显示类型及名称。点标记可编辑原点，返回选点时刷新，离开选点后清除。

### 4. 录入构造交点

用 SCJG 在平面图上点选地层分界线、断层线或褶皱线。一条构造线与剖切线多次相交时，靠近要录入的交点点选。程序取离点选位置最近的实际交点。也可沿用点选剖切线、地表线或手输里程的手工录入。

用通用命令 SX 编辑单根构造线的地质属性。地层分界线、断层线、褶皱的现有图元可在单图元“修改属性”窗口补齐新增字段。上层、下层填地层表的完整编号，例如 T1/2。填写两层的真实倾向、倾角及构造面倾向、倾角，褶皱的构造面指轴面。“上层所在方位”填从构造线指向上层那一侧的平面方位。方位及倾向从正北顺时针填 0～小于 360°，倾角填 0～90°。

程序把上层、下层及各自产状映射到剖面前侧（左）和后侧（右）。字段齐全且方向明确时直接录入。缺失或无效时先点选经过该交点的构造线，再选择地层分界、断层或褶皱类型，填完后把属性写入构造线并重新读取。前后侧不明确时可手工指定上层所在侧。交点按剖面快照保存。分界和断层按构造面产状投影，褶皱标记位置。同里程可同时有厚度点和构造交点。

独立 `SCCOVER` 覆盖层沿用原来的起终点及尖灭约束。基岩构造投影以地表扣除覆盖层厚度后的基岩顶界为起点。

程序取交点处剖切切线方位θ，与真实倾向D求夹角，按cos公式计算带方向视倾角，再按横纵比例计算图上角度。SCAPPDIP可核对界面和两侧岩层的w、真倾角、视倾角及左右倾斜方向；标注仍使用真实倾向、真倾角。拐点两侧切线不一致时停止，不能任选方向。

字高3.5、5.0分别使用宋体3.5、宋体5.0，已有同名样式直接使用，缺少时从 `ProgramTemplate/SectionCutterTextStyles.dxf` 导入。两侧产状文字带边框和背景遮罩，格式随成果保存。已有剖面可以用 `SCTEXT` 原位更新文字格式。

构造投影线独立叠加，厚度层界和填充继续由厚度点计算。

### 5. 补充控制条件

用 `SCPINCH` 输入尖灭控制。需要单独填写水位高程、日期或类型时，运行 `SCWATER`。也可以人工绘制后采纳。

### 6. 生成并修正界线

根据产状投影、厚度控制点、尖灭等条件生成界线草图。允许直接修改 CAD 图形，通过“采纳图形修改”将检查后的改动写回数据。界线交叉、负厚度、归属矛盾或区域未闭合时，定位并提示处理；不对有问题的区域直接填充。

基岩分界和断层投影按起伏基岩顶界裁切。覆盖层和岩层的区域填充取地层表的图案，风化线可跨过地层界线，构造线的错移及褶皱变形由后续版本处理。

### 7. 绘制成果并保存

地层填充、构造线及标注和风化下限线共同绘制，按需生成地下水位线。边框仍按 `ProgramTemplate/地质描述框.dxf` 生成。保存 DWG 后，可用 `SCDRAW` 或 `SCRESTORE` 沿用已确认的图形，用 `SCEXPORT` 导出完整恢复包。

## 二、根据相交的已有剖面生成新剖面

### 1. 设置新剖面并生成地形

选择新平面剖切线，按第一种流程确定方向、比例和基准，并从测量资料生成新剖面的地形。已有剖面提供地下地质控制数据。

### 2. 查找并选择来源剖面

程序逐个询问是否采用与目标相交、具备岩层厚度数据的来源剖面。来源平面线须与已保存线形一致，已采纳或未采纳的人工改线由用户人工取值。

### 3. 在交点读取控制数据

按目标和来源各自的平面比例换算交点里程，读取该位置的岩层厚度。多个来源的岩层代号和层序须一致。覆盖层、风化、构造交点和水位在目标剖面另行录入。

### 4. 复核来源及高程差异

交点基岩顶界高程不一致时显示差值，由用户选择保留界面绝对高程或各层厚度。同里程多个来源冲突时，重新选择一个来源。目标已有统一地层表覆盖层时，使用 `SCEDIT` 补充厚度。

### 5. 连接控制数据

按新剖面实际里程排序，按地层身份匹配相邻控制数据并生成草图。断层、地层归属冲突或缺失需人工处理；缺失不能直接判为尖灭。超出交点范围的两端沿用最近交点数据并标记为外推；仅一个有效交点时提示约束不足，无有效交点时转入人工填图。

新平面剖切线自身的地质交点也作为检查和补充约束；与来源剖面矛盾时由用户确认。

### 6. 共用编辑与出图流程

补充控制点、修正界线、确认尖灭和区域闭合，再生成填充、标注及边框；保存剖面数据、来源及成员关联。

## 三、已有剖面重绘与恢复

1. 从平面线、任一成员或剖面列表选择记录，检查NOD数据、成员存在状态及未采纳修改。
2. 有未采纳改动先采纳或放弃。选择补齐缺失对象、按最后确认成果整体重绘，或者独立进入更新资料流程。
3. 补齐或重绘使用已保存的实际数据和成果，不自动重读源资料；整体重绘可指定新位置。先生成、验证新对象，再更新成员引用并替换旧成果，失败保留原成果。
4. 只有关联失效时先修复，避免重复绘制；平面线丢失仍可从列表重绘，跨剖面取值前须重新关联平面线。
5. NOD丢失而图形尚在时尝试重新登记并提示补充无法还原的信息；图形及数据全失时，从手动恢复包或图纸备份恢复。
6. 提供手动导出和导入恢复包；包含成果、数据、样式及模板版本，导入后新建实体引用，同编号冲突由用户选择恢复或另建副本。普通删图元保留数据，彻底删除剖面数据单独操作。

### 完全重建与无用数据清理

1. `SCREBUILD` 通过平面线、成果成员或列表选择旧剖面；检查身份冲突、复制成员和锁定图层。原平面线不存在时选择替代线。
2. 提醒旧地质数据及人工修改将放弃，确认后从空白参数开始：方向、比例、测量来源、端点高程、基准及绘制位置全部重新确定。
3. 分配唯一新编号、构建并保存新地形，重新关联平面线；随后删除旧成果和旧记录。任何提交失败由命令撤销组回退。取消准备阶段保留旧数据。完成后 `SCDZTT` 重新填图，或通过 `SCDZPM` 连续执行。
4. 同一平面线再次执行 `SCDXPM` 时，先选择 Restore/Update/Rebuild/Cancel，默认取消；前三项分别进入快照恢复、重新取地形和完全重建。
5. `SCCLEAN` 从私有字典枚举真实键与记录，并扫描本程序关联。成果全失、无存活引用的损坏记录及孤立关联列为候选；部分缺失、仍有成果或身份冲突不列为可删记录。
6. DCL默认不选，用户勾选后再次确认放弃恢复依据；提交前重新扫描校验候选并统一检查图层。删除选定记录、解除对应平面关联；孤立关联保留图形及其他属性。只处理SectionCutter数据，不清理共享根字典。
7. 其他剖面的已确认数据不级联删除；`SCCHECK` 报告历史来源失效。清理和重建均支持命令撤销，结果须保存DWG。

## 四、手测修正后的共用步骤（2026-11-04）

1. SCDXPM读取LINE、轻量、旧式二维或三维多段线，保留圆弧参数；检查开放、不自交及XY投影唯一性。WCS XY曲线长度作为平面里程依据。
2. 显示绿起点、红终点及沿切线的黄箭头。空格或回车确认，输入 R 后用空格或回车反向，Esc 取消。查看期间支持滚轮、中键、`'ZOOM` 和 `'PAN`。
3. 测量来源按真实直线/圆弧求交，处理切点、共享端点与闭合段；属性高程优先，否则取来源对应位置Z。缺失端点沿当地切线向外搜索DGX，默认插值并允许手工输入。保存选择结果及来源。
   水平旧式二维拟合来源使用CAD原生曲线求交；先按包围盒排除无关来源，再临时复制并将副本高程置零求XY交点，取回来源原高程，完成后清理。禁止炸开或修改原始DGX。
   LINE按完整起终点读取为一段，保留短线和非整数尾段。首末测量点对齐使用同一数值容差，已有末端交点不因浮点误差重复补点。
4. SCSCPM对目标与来源分别按各自曲线和比例换算交点实际里程；产状投影按交点当地切线计算。新数据保存曲线快照，旧直线模型仍使用原里程；线形变动提示新建。
5. 出图前分别检查横向500组、纵向300组上限。允许500个完整横向间隔及501个刻度位置；超限显示当前组数和最小间距，等待用户调整参数。
6. 由模板闭合多段线和水平线端点读取所有栏目边界，空描述仍生成完整底框。新建成果使用修正图框；旧成果运行SCFRAME更新框线、标尺和栏目文字，保留地质实体及人工改动，成功保存新框快照。普通恢复不擅自更换模板版本。
